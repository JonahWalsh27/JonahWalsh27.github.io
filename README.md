# Jonah Walsh — Personal Portfolio

Cybersecurity student and Artificial Intelligence Intern at Rhode Island College.

**Portfolio:** https://jonahwalsh27.github.io

This is a responsive, dark-themed portfolio built with HTML, CSS, and a little JavaScript.

## Sections
About Me, Projects, Skills, Education, Experience, Resume, Contact.

## Publish with GitHub Pages
Go to **Settings → Pages → Build and deployment**, select **Deploy from a branch**, choose **main** and **/(root)**, and save.

## Resume download
The site currently provides an email link to request the resume, because no resume PDF has been uploaded. To enable a direct download, upload `resume.pdf` and replace the resume section's email link in `index.html` with `<a class="btn secondary" href="/resume.pdf" download>Download My Resume</a>`.

## Editing
Update text and links directly in `index.html`. No dependencies or build process required.
